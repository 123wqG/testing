# 公务员备考个人工作台 · 本地验收版

## 实施顺序
1. 项目及数据库设计；2. 完整页面；3. 待办；4. 每日模板；5. 计时；6. 资料；7. 图片；8. Supabase 适配；9. 登录同步；10. 移动端；11. PWA；12. 本地测试。

## 页面设计
白色 #ffffff、浅灰 #f6f7f8、边框 #e6e9e8、正文 #242c29、辅助文字 #6d7771、强调绿 #426b58。系统字体，正文 15px，页标题 30px。桌面 224px 左导航，正文最大 1040px；手机单列与底部导航。任务使用分隔线列表，只有资料入口与图片笔记使用卡片。浅色默认，可切深色。

首页以当天日期和可直接填写的添加框为中心，统计占一行。空白初始数据，无假学习记录。图像不作装饰，留给真正的学习截图。遵循需求的静谧工作台风格，不增加图表或打卡游戏。

桌面：左导航 | 日期、摘要 / 今日任务 / 行测和申论入口。
手机：日期、摘要 / 今日任务 / 资料入口 / 固定底导航。

## 代码结构
- src/app.js：启动、导航、事件与页面协调
- src/ui.js、styles.css：页面和样式
- src/core.js：日期、任务模板、计时汇总等纯逻辑
- src/store.js：状态与操作，调用统一数据接口
- src/data/local.js：IndexedDB 数据与 Blob 图片，本地验收模式
- src/data/supabase.js：Auth、数据库、私有 Storage
- src/images.js：图片验证、缩略图
- supabase/schema.sql：表、关系、原子操作、RLS、Storage 权限
- public：PWA 清单、图标和基础 service worker

## 数据模型
tasks：id、user_id、date、title、done、estimated_minutes、manual_minutes、note、position、template_id、template_date、created_at、updated_at、deleted_at。
daily_task_templates：id、user_id、title、estimated_minutes、note、enabled、created_at、updated_at、deleted_at。
study_sessions：id、user_id、task_id、date、duration_seconds、created_at。手动分钟与计时秒数相加；手动修改只修改手动部分。
study_materials：id、user_id、section（行测/申论）、title、note、tags、created_at、updated_at、deleted_at。
material_images：id、user_id、material_id、path、thumbnail_path、position、created_at。

模板与日任务独立。模板只在访问当天时生成，不伪造未访问日期的任务。template_id + template_date 唯一防重；删除当天任务保留软删除记录，避免复活。顺延任务保留来源日期标记，目标日期的固定任务仍独立生成。

云模式所有写入先经过服务端再更新界面，不把未上传的变化标为同步成功。失网明确失败，可重试；不会偷偷切回本地。页面重新获得焦点或点击刷新读取云端。跨设备同时修改同一记录采用最后成功写入的记录；计时记录按独立 ID 幂等追加。活动计时器属于当前浏览器，结束后上传。图片原图及缩略图分开保存，以短期签名地址访问。

## 阶段边界
只开发、构建、预览、测试。没有创建仓库、提交、推送或部署。真实 Supabase 项目需要用户提供公开配置并在控制台创建个人账号、执行 SQL 后才可实测。
